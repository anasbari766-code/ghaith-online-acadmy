غیث آنلاین آکادمي — نسخه ابتدایی وب‌سایت

فایل اصلی: index.html
این نسخه شامل صفحه اصلی، معرفی دوره‌ها، معرفی آکادمی، فرم ثبت‌نام نمایشی و تغییر زبان میان پشتو، دری و عربی است.

مهم:
فرم فعلاً نمایشی است و اطلاعات شاگردان را ذخیره یا ارسال نمی‌کند. پیش از استفاده واقعی باید فرم به یک سرویس دریافت اطلاعات یا پایگاه داده وصل شود. اطلاعات شاگردان را در نسخه فعلی وارد و استفاده نکنید.

برای آزمایش:
1. فایل index.html را در مرورگر باز کنید.
2. روی دکمه‌های زبان کلیک کنید.
3. نسخه موبایل را با باز کردن فایل در مرورگر تلفن آزمایش کنید.

برای انتشار بعدی:
می‌توان این فایل را روی میزبانی استاتیک مانند GitHub Pages یا Netlify منتشر کرد. برای دریافت امن ثبت‌نام‌ها، در مرحله بعد باید سرویس فرم و دسترسی مدیر را تنظیم کنیم.
